U3

Over mij

Ik ben developer met de meeste expertise in de backend. Ik heb ook ervaring met frontend en devops en kan die taken zelf oppakken.

Ik programmeer sinds mijn elfde. Die ervaring gebruik ik om je project en mijn teamgenoten een stap verder te brengen.

Ik denk niet in problemen maar in uitdagingen en creatieve oplossingen, dus er is weinig dat ik niet wil bouwen.

U4

Wat ik goed kan

Multidisciplinair

Mijn interesse in code en techniek is breed en ik leer graag nieuwe dingen. Ik schrijf meer dan tien programmeertalen, dus iets nieuws is zelden een probleem en meestal een leuke uitdaging.

Technisch leiderschap

Met mijn brede technische kennis maak ik technische beslissingen en voer ik ze door, in het vertrouwen dat ze werken. Ik kan zelfstandig een project opzetten en afronden volgens hoge kwaliteitsstandaarden. Daarnaast coach ik graag collega's en til ik ze mee naar een hoger niveau.

Oplossingsgericht

Tijdens het refinen van taken zie ik snel de oplossing voor complexe uitdagingen. Daardoor weet ik ook goed hoeveel moeite nodig is om zo'n uitdaging tot een succes te maken.

Laravel-expert

PHP programmeer ik sinds mijn elfde en Laravel gebruik ik sinds versie 5.3 (2016), samen met veel verschillende front-endtechnieken. Er is niets in de PHP-wereld dat nog nieuw voor me is. Door die kennis van het landschap kan ik voor elke klus de juiste tools aanraden.
